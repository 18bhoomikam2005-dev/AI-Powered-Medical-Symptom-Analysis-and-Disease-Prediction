
# Health Risk Assessment System

## Project Overview
A machine learning based health risk assessment system that predicts diseases
from patient symptoms, evaluates risk and severity, generates recommendations,
and provides health reports and analytics.

## Dataset
Disease Symptoms and Patient Profile Dataset

Features include:
- Fever
- Cough
- Fatigue
- Difficulty Breathing
- Age
- Gender
- Blood Pressure
- Cholesterol Level
- Outcome Variable

Target:
- Disease

## System Workflow

Patient Data
     ↓
Data Preprocessing
     ↓
Disease Prediction
     ↓
Disease Probability
     ↓
Risk Assessment
     ↓
Treatment Recommendation
     ↓
Health Report
     ↓
Analytics Dashboard
